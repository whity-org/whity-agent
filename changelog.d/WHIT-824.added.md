- **Windsurf and Claude Desktop can connect, through a local bridge.** They can't sign in to a remote server themselves, so their config now runs `whity-agent mcp --connection <id>`, which relays MCP to your workspace. The file holds no token and no address, only that command: your sign-in stays in your computer's keychain. You review the change first, as for any other tool, and can disconnect or put the file back. Access tokens now renew when they expire or the server refuses one, and every Whity Agent process takes turns refreshing, so several tools at once can't sign you out (WHIT-824).
