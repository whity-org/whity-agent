- **Whity Agent lives in the tray.** Closing the window keeps it running, so a chat or an update carries on, and Quit in the tray menu ends it. Only one copy runs at a time. You can choose to start it when you sign in to your computer, and then it waits in the tray.
- **`whity-agent://connect?instance=<address>` links.** A link opens the app with the workspace's address filled in. It never signs in or changes anything by itself (WHIT-824).
