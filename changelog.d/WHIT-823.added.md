- **Find your AI tools and connect them to a workspace.** whity-agent looks for Claude Code, Codex CLI, Gemini CLI, VS Code, Cursor, Windsurf and Claude Desktop on this computer, only by checking PATH and their config files, never by running them. Connecting is always two steps: you see exactly what will happen first (the tool's own "add server" command, or the config file before and after), and nothing changes until you confirm. Tools that sign in by themselves get the workspace's address only, never a token. A file is changed only if it's still as you reviewed it, only our entry is touched, a backup is kept, and the write is atomic; Disconnect takes our entry out and "Put the file back" restores the backup. Windsurf and Claude Desktop wait for the local bridge (WHIT-823).
