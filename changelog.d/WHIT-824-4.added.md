- **Installers and signed updates.** Each release builds Windows, macOS and Linux installers, with SHA-256 checksums and install notes in English and Arabic (`docs/INSTALL.md`). Whity Agent checks for updates when it opens and once a day, downloads them in the background and restarts when you choose. An update that doesn't carry our signature is never installed. The installers themselves aren't signed with a paid certificate yet, so Windows and macOS warn on first install (WHIT-824).
- **Tools are found when the app is opened from the Dock or a launcher.** On macOS and Linux it now also looks in the usual install folders, and an AppImage records its real path in a tool's config.
